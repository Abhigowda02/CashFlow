# CashFlow Contract Endpoints

This document specifies the target API endpoints to be implemented across upcoming prompts.
All request and response shapes map directly to Pydantic models in `shared/schema.py` and TypeScript definitions in `frontend/src/types/contract.ts`.

---

## 1. State & Freshness

### `GET /api/state`
Returns the business dashboard state, including basic business info, cash balance, freshness status, and summary counts.
- **Response**:
  ```json
  {
    "business_id": "b-1",
    "name": "Apex Enterprises",
    "as_of": "2026-10-24",
    "cash_balance": 450000,
    "cash_updated_on": "2026-10-24T18:30:00Z",
    "safety_floor": 100000,
    "stale": false,
    "open_invoices_count": 8,
    "unresolved_alerts_count": 2,
    "pending_actions_count": 3
  }
  ```

---

## 2. Forecast & Evaluation

### `GET /api/forecast/view`
Unified 90-day cash flow forecast view for the dashboard and forecast page.
- **Response Model**: `shared.schema.ForecastView`
- **Fields**: `headline`, `generated_at`, `as_of`, `cash_last_updated`, `stale`, `dates` (90), `p10` (90), `p50` (90), `p90` (90), `safety_floor`, `shortage_prob`, `first_shortage_date`, `min_balance_p50`, `why` (list of `WhyItem`), `warnings` (list of str), `accuracy` (`ForecastAccuracy` or null).

### `GET /api/forecast/backtest`
Historical walk-forward backtest evaluation on settled payment dates.
- **Response**:
  ```json
  {
    "mape": 0.082,
    "median_abs_error_days": 4.5,
    "p10_p90_coverage": 0.81,
    "backtest_dataset": "public_sample",
    "n_invoices_evaluated": 2500,
    "evaluated_at": "2026-10-24T00:00:00Z",
    "caveats": "Evaluated on historical MSME trade credit dataset."
  }
  ```

## 3. Invoices & Customers

### `GET /api/invoices`
Returns list of invoices for the current business session.
- **Response Model**: `list[shared.schema.Invoice]`

### `POST /api/invoices`
Creates or updates a single invoice.
- **Request Body**: `shared.schema.Invoice`
- **Response Model**: `shared.schema.Invoice`

### `POST /api/invoices/preview`
Uploads and parses a CSV, Excel, or PDF document for invoice preview without saving.
- **Response**: `{"invoices": list[Invoice], "mapping": dict, "confidence": float, "duplicates": list[str]}`

### `POST /api/invoices/commit`
Commits previewed and reviewed invoices to the database.
- **Request Body**: `{"invoices": list[Invoice], "mode": "append|replace"}`
- **Response**: `{"imported_count": int, "status": "ok"}`

---

## 4. Alerts

### `GET /api/alerts`
Retrieves actionable alerts for cash shortages, MSME section 43B(h) deadlines, and overdue invoices.
- **Response Model**: `list[shared.schema.Alert]`

### `POST /api/alerts/{id}/read`
Marks a specific alert as read.
- **Response**: `{"status": "ok", "alert": shared.schema.Alert}`

---

## 5. Collections & Reminders

### `GET /api/reminders/queue`
Returns the pending collections reminder queue (approval-first workflow).
- **Response Model**: `list[shared.schema.Reminder]`

### `POST /api/reminders/{id}/approve`
Owner approves a draft reminder for dispatch.
- **Response Model**: `shared.schema.Reminder` (status set to `approved`)

### `POST /api/reminders/{id}/send`
Dispatches the approved reminder via the selected channel (WhatsApp, email, or SMS).
- **Response Model**: `shared.schema.Reminder` (status set to `sent`, `sent_at` timestamp recorded)

---

## 6. Actions Copilot

### `GET /api/actions/cards`
Returns ranked corrective action cards generated by the forecast engine.
- **Response Model**: `list[shared.schema.ActionCard]`

### `POST /api/actions/{id}/execute`
Executes or stages the chosen action card.
- **Response**: `{"status": "executed", "action_id": str, "effect": shared.schema.ActionEffect}`

---

## 7. Bank Transactions & Connected Accounts

### `GET /api/transactions`
List imported or ingested bank transactions.
- **Response Model**: `list[shared.schema.Transaction]`

### `POST /api/transactions/import`
Uploads bank statement file (CSV, OFX, PDF) and parses transactions with deduplication.
- **Response**: `{"imported_count": int, "transactions": list[Transaction]}`

### `GET /api/transactions/proposed-obligations`
Recurring payment patterns detected from transactions awaiting user confirmation.
- **Response Model**: `list[shared.schema.ProposedObligation]`

### `GET /api/transactions/proposed-matches`
Matches detected between bank transactions and invoices or supplier bills.
- **Response Model**: `list[shared.schema.ProposedMatch]`

### `POST /api/connect/bank`
Initiates bank connection via Account Aggregator sandbox / mock adapter.
- **Request Body**: `{"consent_handle": str, "fi_types": list[str]}`
- **Response**: `{"status": "connected", "accounts": int, "consent_id": str}`

### `POST /api/connect/sms`
Parses pasted or forwarded bank transactional SMS messages.
- **Request Body**: `{"sms_text": str}`
- **Response**: `{"status": "parsed", "transactions": list[Transaction]}`
